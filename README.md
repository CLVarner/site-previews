# Website prototype reviews

This public repository hosts approved static homepage review packages through GitHub Pages. The gallery starts empty; review rounds appear when they are ready to share.

Open a round, compare its responsive concepts, or download an individual HTML file/the complete ZIP. Gallery feedback stays in your browser until you download it; send that text through the review channel agreed with the project owner.

Only presentation exports and selected web assets belong here. Source repositories, research documents, agent instructions, complete brand kits, QA/source records, approval identities and collected feedback remain private. Demonstration actions do not process payments or submit forms.

`public/` is the only Pages deployment directory. `sharing.json` identifies this checkout as the approved-export destination. Reviewed round content remains frozen while published; revisions get new round IDs. GitHub Pages shows only the latest approved round for each site. Remove the superseded public directory and catalog entry when publishing its replacement; private source rounds and Git history retain earlier work. Keep other sites’ current previews. Pushing approved changes on `main` deploys the public gallery using GitHub Actions.

Everything committed here is public. `noindex` and `robots.txt` are search-engine requests, not privacy controls.
